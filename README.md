### 🚀 Featured projects

| Project | What it does | Built with |
|---|---|---|
| [**sapply**](https://github.com/Kyo1y/sapply) | My automated job-search pipeline. It pulls fresh new-grad roles from several sources on a schedule, dedupes and ranks them against my profile, finds the right recruiters and drafts source-backed outreach emails. I still review, apply and hit send myself | TypeScript, Cloudflare Workers (D1, Queues, Cron), Drizzle ORM, OpenAI |
| [**Baton**](https://github.com/Kyo1y/Baton) · [live](https://www.batonnn.com) | Moves playlists between Spotify and YouTube Music, with live progress tracking and transfer history | Next.js 15, TypeScript, NextAuth, Prisma, AWS DynamoDB, OpenAI |
| [**Letterhead**](https://github.com/Kyo1y/Letterhead) | Chromium extension that spots job postings and LinkedIn profiles and writes tailored cover letters and outreach messages on the spot | JavaScript, Chrome Extensions API, LLM APIs |
